Managed Disks, explained from scratch

Understand OS vs data disks, Standard HDD, SSD and Premium tiers, snapshots and encryption.

What is a Managed Disk?

A Managed Disk is a storage volume attached to a VM that holds your operating system or data files. Unlike old "unmanaged" disks, Azure handles all the complexity: redundancy, encryption, snapshots, and scaling. You just attach it to a VM and use it like a normal drive.

OS Disk vs Data Disk

Every VM has an OS disk (holds Windows or Linux), which is required and non-negotiable. You can attach additional data disks for files, databases, or backups. A single VM can have up to 64 data disks, each up to 32 TB. You mount them just like on-premises drives.

Disk Tiers & Performance

  • Standard HDD — cheap, slow, for non-critical workloads (dev/test).
  • Standard SSD — balanced cost and speed, good for most production apps.
  • Premium SSD — fast, expensive, for I/O-heavy databases and real-time apps.
  • Ultra Disk — fastest option, for mission-critical databases requiring lowest latency.

Snapshots & Backup

Take a snapshot of any disk to create a point-in-time copy. Snapshots are cheap to store (you pay only for the changed blocks) and let you quickly restore or clone disks. Use them before major updates, or to duplicate a configured disk for multiple VMs.

Getting Started

When creating a VM, choose disk type and size. After deployment, attach new data disks via the Portal. In the OS, initialize and format them. To snapshot: Portal → Disk → Create Snapshot. To restore: create a new disk from the snapshot. Most beginners start with Standard SSD and upgrade to Premium only if performance becomes a bottleneck.
